# Demo seeds

รัน migrations ให้ครบก่อน แล้วเปิด Supabase SQL Editor และรันไฟล์
ตามลำดับ:

1. `grade_review_end_to_end_demo.sql`
2. `grade_results_multi_subject_demo.sql`

ชุดข้อมูลนี้แยกอยู่ในโรงเรียน `โรงเรียนสาธิตระบบผลการเรียน` และรันซ้ำได้
โดยจะอัปเดตข้อมูลเดโมชุดเดิม

หากรอบก่อนหน้าแสดง `Student account is not eligible for enrollment`
ให้ใช้ไฟล์เวอร์ชันล่าสุดแล้วรันใหม่ตามลำดับด้านบน Seed จะปรับบัญชีเดโมให้เป็น
`student / studying / active` ก่อนลงทะเบียนเข้าห้องโดยอัตโนมัติ

Seed หลายวิชาเวอร์ชันล่าสุดใช้ UUID นักเรียนช่วงแยกจาก Admin/Teacher
และซ่อม role ของบัญชีเดโมเดิมอัตโนมัติ หลังรันเพื่อซ่อมข้อมูลแล้วให้ Sign out
และ Sign in ใหม่ เพื่อให้ session รับ role ล่าสุดจากฐานข้อมูล

## หน้าที่ใช้ตรวจสอบ

1. `/admin/grade-reviews` — รายการตรวจสอบและประวัติ workflow
2. `/admin/grade-reviews/grade/ประถมศึกษาปีที่%201` — รายวิชาระดับชั้น
3. `/admin/grade-results` — ผลการเรียนแบบรายชั้นเรียน
4. `/admin/grade-results/classroom/de000000-0000-4000-8000-000000000120/de000000-0000-4000-8000-000000000110`
   — รายวิชาภายในชั้นเรียน
5. `/admin/grade-results/de000000-0000-4000-8000-000000000140`
   — รายละเอียดภาษาไทยและ PDF ปพ.5
6. `/admin/documents/pp5` — เมนูเอกสาร ปพ.5

หลังรันทั้งสองไฟล์ ข้อมูลตัวอย่างประกอบด้วย:

- 1 ชั้นเรียน 1 ภาคเรียน
- 5 รายวิชา
- นักเรียน 20 คน
- งานคะแนนวิชาละ 5 หมวด รวมคะแนนเต็ม 100
- ผลการเรียนรายนักเรียน–รายวิชา 100 ชุด
- ผลพิเศษ `ร`, `มส`, `มผ`
- ผลประเมินคุณลักษณะ การอ่านคิดวิเคราะห์และเขียน และกิจกรรมพัฒนาผู้เรียน
- ประวัติ `ส่งตรวจ → ตรวจแล้ว → อนุมัติ/ปิดผล`
- ผู้ปกครองตัวอย่าง 20 คน โดยไม่ใส่ LINE user id ปลอม
